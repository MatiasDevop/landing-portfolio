# SMIT UI/UX Designer Portfolio

Next.js 16 app (React 19, Tailwind CSS v4). Original design: [Figma – SMIT UI/UX Designer Portfolio](https://www.figma.com/design/kC5pezU8UPHWXYEOs9fxUU/SMIT-UI-UX-Designer-Portfolio).

## Setup

This project uses **pnpm** as the package manager.

```bash
pnpm install
```

## Scripts

- **`pnpm dev`** – Start the development server (Turbopack)
- **`pnpm build`** – Build for production
- **`pnpm start`** – Run the production build
- **`pnpm lint`** – Run ESLint

## Stack

- **Next.js 16** (App Router, Turbopack)
- **React 19**
- **Tailwind CSS v4**
- **TypeScript 5.7+**
